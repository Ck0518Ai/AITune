# AITune

AI가 조율하는 새로운 음악의 미래 — **Tune Your Future with AI**

AITune은 AI 생성 음악을 만들고, 발견하고, 구매하고, 판매할 수 있는 음악 플랫폼 랜딩 페이지입니다.

## 기술 스택

- HTML5
- CSS3 (반응형 디자인)
- JavaScript (Vanilla)

## 실행 방법

1. 저장소를 클론합니다.
   ```bash
   git clone https://github.com/Ck0518Ai/AITune.git
   ```
2. `index.html` 파일을 브라우저에서 엽니다.

## 주요 기능

- AITune 브랜드 소개 및 핵심 가치
- Create / Discover / Buy / Sell 서비스 안내
- 인기 트랙 카탈로그
- 모바일 반응형 UI
